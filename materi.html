Silabus Pembelajaran


Pada pertemuan ini, kita akan mempelajari struktur dasar HTML, styling menggunakan CSS, dan interaktivitas dengan JavaScript. Materi ini sangat penting sebagai fondasi dalam membangun website.


Target Pembelajaran:

  1. Memahami struktur dokumen HTML.
  2. Mampu menggunakan CSS untuk layout (Flexbox/Grid).
  3. Mengetahui dasar-dasar manipulasi DOM dengan JavaScript.

Tools yang Diperlukan:

  • Text Editor (VS Code / Sublime Text).
  • Web Browser (Google Chrome / Mozilla Firefox).
